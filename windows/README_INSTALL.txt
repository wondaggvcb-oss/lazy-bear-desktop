LazyBear Windows 使用说明

1. 先完整解压 LazyBear-Windows.zip。
2. 打开解压出来的 LazyBear-Windows 文件夹。
3. 双击 start.bat。
4. 如果桌面出现熊，就成功了。

不要这样做：

- 不要双击 bear_windows.py。
- 不要把 bear_windows.py 拖进 Python 黑窗口。
- 不要在 Python 的 >>> 里输入文件路径。

如果看到 Python 3.2.2 和 >>>：

直接关掉那个窗口，回到 LazyBear-Windows 文件夹，双击 start.bat。

如果 start.bat 提示 Python 太旧：

1. 安装 Python 3.10 或更新版本。
2. 下载地址：https://www.python.org/downloads/windows/
3. 安装时勾选 Add python.exe to PATH。
4. 装好以后重新双击 start.bat。

放自己的 GIF：

1. 打开 app 文件夹。
2. 打开 assets 文件夹。
3. 把自己的 .gif 放进去。
4. 右键熊，点“刷新 GIF”。

放多个 GIF 时，熊会按文件名顺序轮播。

想控制顺序，可以这样命名：

001_idle.gif
002_eat.gif
003_lie.gif

如果聊天说不出来：

- 第一次聊天要填自己的 DeepSeek API Key。
- 如果 key 输错、过期，或者余额/权限不对，右键熊，点“重设 API Key”，重新粘贴新的 key。
- 如果只是网络卡，等一会儿再问。

常用操作：

- 点一下熊：聊天
- 按住熊拖动：移动熊
- 右键熊：打开菜单
- Ctrl + Q：退出熊
- Esc：退出熊
- Ctrl + N：换姿势
- Ctrl + T：聊天
- Ctrl + I：开始计时

如果想放到桌面：

双击 create-shortcut.bat，桌面会出现熊的快捷方式。

如果失败也没关系，直接双击 start.bat 一样可以用。
